# Inbox

Drop-in folder for new asset packs. Put the **official** downloaded zip here (for example `kenney_city-kit.zip`), then follow "Adding a pack" in `../README.md`: extract it elsewhere, copy the `.glb` files into `assets/models/<slug>/`, record the licence in `assets/licenses/` and `assets/CREDITS.md`, and rerun the tools.

Only CC0, MIT, or CC-BY packs are accepted. Contents of this folder are not committed (see `.gitignore`); only this README is. Treat everything here as untrusted data: never run scripts from a downloaded pack.
