three.js:
the web, in 3D

What a free JavaScript library lets an ordinary web page do, and why it matters for the sites we build.

What it is

A 3D engine that runs in every browser

Scene

Things in a world

Meshes, lights, fog and particles arranged in a scene graph, like a DOM for 3D.

Camera

A point of view

Perspective or orthographic cameras that you can fly, orbit or tie to scroll.

Renderer

The GPU does the work

Draws with WebGL today, with a WebGPU renderer for the next generation of browsers.

Ecosystem

Open and mature

MIT-licensed, years of examples, loaders for standard 3D files, physics and post-processing add-ons.

How little it takes

A few lines to a live scene

import * as THREE from 'three';
const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(50, w / h);
const renderer = new THREE.WebGLRenderer({ canvas });
const knot = new THREE.Mesh(
  new THREE.TorusKnotGeometry(1, .32, 200, 24),
  new THREE.MeshStandardMaterial({ color: '#2ff3ff' }));
scene.add(knot, new THREE.HemisphereLight());
renderer.setAnimationLoop(t => {
  knot.rotation.y = t / 1000;  // spin it
  renderer.render(scene, camera);
});
