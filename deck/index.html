3D on the web,
without the app

What three.js lets a plain web page do today, and where it could make public information pages feel like places worth visiting.

Back to Neon Coast

Why now

The browser is a 3D engine already

No install

A link opens it. No app store, no plugin, works on phones and laptops.

Small

A whole world can ship in one HTML file of a megabyte or two, because shapes, textures and sound can be generated by code.

Web skills we have

It's JavaScript, HTML and CSS: the same tools our team uses every day, with three.js handling WebGL.

Mixes with the page

Real HTML text, buttons and forms sit on top of the 3D, so accessibility and SEO still work.

Example 3 · from the community

Lumen Isles

A night flight over glowing floating islands, written in one HTML file with raw WebGL2 and no libraries at all. Ideas worth borrowing:

Adaptive quality

It lowers its own resolution when frames run slow, so weaker devices stay smooth.

Light that spreads

Glowing plants are painted into a top-down light map that tints the ground around them.

Cinematic mode

A slow camera orbit for presenting, plus bloom and soft god-rays for atmosphere.

By moritzkremb · source on GitHub

Use case · government information pages

The state museum, in the browser

  • Today: text, opening hours, a PDF, a small photo carousel.
  • Turn the object: 3D artefacts you can rotate, zoom and relight.
  • Hotspots: tap for captions, audio guide and sign-language video.
  • Plan the visit: walk the galleries, check lifts and accessible routes.
  • Exhibits that can't travel: fragile pieces shown to regional schools.

Live demo: a vase made entirely in code. Drag to turn it, tap the gold dots.

Tap a gold dot to read about that part of the vase.

Doing it responsibly

3D that still meets the bar

Accessible

Real HTML text beside the 3D, keyboard controls, captions, reduced-motion support.

Fallback

A plain 2D page or images when WebGL is missing or the device is slow.

Budget

Set a size and draw-call budget, cap pixel ratio, pause when the tab is hidden.

Licensed assets

Code-generated or CC0/MIT models with credits recorded; never ripped content.
